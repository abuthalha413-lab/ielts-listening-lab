IELTS LISTENING LAB — VERSION 2

How to run:
1. Extract the ZIP.
2. Open the folder.
3. Double-click index.html.
4. Use Chrome or Edge.

Included:
- Original 40-question IELTS-style listening test
- 4 sections
- 30-minute timer
- Browser speech audio for the original script
- Automatic marking and answer review
- Recent score history using browser localStorage
- User uploaded Test 1 MP3
- Responsive phone/laptop layout

Important:
The supplied PDF was not copied into the app because it contains copyrighted test content. Add only material you own or have permission to use.
The displayed band conversion is a prototype estimate, not an official IELTS score conversion.
